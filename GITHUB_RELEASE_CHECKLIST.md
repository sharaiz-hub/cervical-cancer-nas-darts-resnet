# GitHub release checklist

- [x] Clear original-author and maintainer distinction
- [x] Documentation of known methodology and historical results limitations
- [x] Navigation, existing figure gallery and setup notes
- [ ] Confirm upstream repository license and copyright requirements
- [ ] Confirm permission to redistribute all source, pretrained checkpoints, screenshots and images
- [ ] Confirm any client delivery contract permits repository hosting (including private hosting)
- [ ] Review GitHub private repository access and collaborators
- [ ] Perform comprehensive secrets/privacy scan (including binary artifacts)
- [ ] Verify checkpoint loading and frontend/backend runtime
- [ ] Build clean, seeded, group-disjoint evaluation protocol before claiming benchmark results
- [ ] Obtain permission before changing visibility to public

**Private GitHub upload is the intended review target, not a blanket authorization to redistribute third-party work.**
