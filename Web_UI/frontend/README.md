# Cervical Cell Classification — Web UI

React/Vite interface for the existing DARTS-style cervical cytology cell classifier. **Maintained by Sharaiz Shahid; original implementation by Dhanush Saravanan.** No inference code was modified as part of the documentation pass.

From this directory: `npm install` then `npm run dev`. Backend lives in `../backend` and uses FastAPI; follow its dependencies and startup assumptions. The UI is a research demonstration, **not a clinical diagnosis service**. Do not expose it publicly without input validation, security review, and model validation.
